## Layout and grid

Good layout is mostly **alignment** and **consistent rhythm**.

### Core rules
- **Use a grid.** 12-column for complex pages; simple flex/grid for most. Align edges.
- **Max content width.** Long-form text should sit around 60-75 characters per line
  (~680-760px). Full-bleed is for heroes/media, not paragraphs.
- **Consistent gutters.** Horizontal page padding and gaps come from the spacing scale.
- **Vertical rhythm.** Space between sections should be larger than space within a section
  (e.g. section gap 64-96px, intra-group gap 12-24px). Proximity communicates grouping.
- **Alignment over centering.** Left-align body text and form fields; reserve centering
  for short headings and hero content.

### Responsive structure
- Design mobile-first; let multi-column grids collapse to one column.
- Keep a single max-width container and center it; don't let content touch screen edges.

### Review questions
- Do element edges line up on an invisible grid?
- Is paragraph measure comfortable (not too wide)?
- Is there clear, consistent spacing between and within sections?
