## Visual hierarchy

Every screen should answer instantly: "Where do I look first? What matters most?"

### Tools for creating hierarchy (strongest to subtlest)
1. **Size** — larger elements read as more important.
2. **Weight** — bolder text/heavier shapes draw attention.
3. **Color & contrast** — high contrast and brand color pull focus; mute the rest.
4. **Spacing** — whitespace isolates and elevates; grouping implies relationship.
5. **Position** — top-left and center get seen first (LTR reading); corners get scanned.

### Principles
- **One primary action per view.** Make it the single highest-contrast element.
  Secondary actions are ghost/outline; tertiary are plain text links.
- **Limit focal points.** If everything shouts, nothing is heard. Pick 1 hero element.
- **Use a clear type scale** so headings, subheadings, and body are visibly distinct.
- **Progressive disclosure** — hide advanced/rare options until needed.

### Review questions
- Can a first-time user find the main action in under 2 seconds?
- Are there competing elements with equal visual weight?
- Does whitespace group related items and separate unrelated ones?
